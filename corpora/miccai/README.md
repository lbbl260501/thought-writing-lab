# MICCAI 2025–2026 · 研究与英语写作语料工程

**性质：** 这是一个公开的 *分析索引与原创知识萃取层*，不是受版权保护论文的镜像下载站。

## 官方入口与阶段

- [MICCAI 2025 Open Access](https://papers.miccai.org/miccai-2025/) — 官方公布主会录用 1,027 篇。
- [MICCAI 2026 Open Access](https://papers.miccai.org/miccai-2026/) — 官方公布主会录用 1,167 篇。
- 2025+2026 共 **2,194 篇录用论文**（统计口径为官方主会，不包含卫星活动）。
- **当前状态：仅完成 9 篇人工精选样本的官方页面核验，未完成 2,194 篇全量抓取与全文精读。**
- [首批 9 篇元数据](pilot/pilot_catalog.csv)；[示范分析](pilot/)；[分层标注方案](ANNOTATION_GUIDE.md)。

官方开放版本与录用稿内容一致，但版权属于相关权利人。此处只保存引用元信息、来源 URL 和原创分析；原始 PDF 按授权条件单独保管。

## 目的：五层同时萃取，而不只是收集“漂亮句子”

| Layer | What is extracted | Reuse |
| --- | --- | --- |
| L1 Linguistic | 主体—动作—客体、句法、动词、搭配、限定表达 | 句子小练习、学术英语语言库 |
| L2 Narrative | 句子/段落的叙事动作、信息顺序、研究故事 | 摘要、引言、章节结构 |
| L3 Argument | 主张、推理依据、反例、竞争解释、证据与结论关系 | 论证链、结果与讨论、审稿回应 |
| L4 Scientific construction | 问题抽象、潜在假设、数学建模、设计原则、实验识别 | 理论构建、模型改进、科研选题 |
| L5 Evaluation/strategy | 贡献类型、受众定位、评审质疑、说服策略 | 叙事框架重构、研究规划 |

对每篇研究不强求存在五层的全部成果；缺少相关证据就留空。

## 工作模式

1. 从官方网页建立完整、去重的元数据索引（优先 ID、标题、作者、年份、官方页面、PDF 链接），**不默认下载所有 PDF**。
2. 采用分层抽样，按研究方向与论文论证类型确保多样性；Oral/Spotlight 加权须核对当年官方日程，不凭猜测给标签。
3. 对优选论文逐篇进行 PDF 核读、引言与方法/实验标注，记录页码位置。公开评审和作者回复作为单独的 *reviewer perspective*。
4. 跨论文聚合同类思想动作；开发表达小练习与研究级任务。
5. 质量检查后回流 [知识方法库](../../knowledge/) 与 [课程](../../courses/)。
