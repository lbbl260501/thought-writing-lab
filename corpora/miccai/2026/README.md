# MICCAI 2026 · 论文来源、问题定义与学术叙事（B 研究组）

本目录是 Thought Writing Lab [Issue #3](https://github.com/lbbl260501/thought-writing-lab/issues/3) 的独立科研语料工作区，对应长期 [P-Corpus #7](https://github.com/lbbl260501/thought-writing-lab/issues/7)。研究目的不是存放大量论文 PDF 或孤立的写作模板，而是建立一条可核验、可审校、可迁移的路径：

**官方论文来源 → 问题与假设 → 科学主张与证据 → 评审挑战 → 可判别的新实验 → 英语叙事及科研训练。**

## B 的研究主线

1. **科学问题如何被构建：** 区分从性能短板出发、从评价对象出发、从概念定义出发、从工作流程出发和从理论矛盾出发的不同创新路径。
2. **科学论证如何获得可信度：** 把 *author claim*、审稿意见、研究者解读和新的可检验假设分开，尤其关注证据是否真的判别了竞争解释。
3. **方法与问题的关系：** 追问一个模型模块是任务所需、结构先验还是经验选择；避免把方法新奇性直接等同于科学问题新颖性。
4. **与写作和理论工作组衔接：** 向 C 提供可溯源叙事动作和论证语言问题；向 D 提供可构成形式化、反例与实验设计的真实研究矛盾；由 HQ 决定通用标注与课程整合。
