## 五篇引言分别学什么

**FRODO / Paper5533**：从不同模态承担的证据角色，走向可检验的非对称建模关系。重点不是一句“互补”，而是怎样说明分工。

**MWA 替代模型 / Paper4859**：将单次预测速度放进反复比较候选方案的过程，解释效率为何改变规划能力。

**MA-MoE / Paper1806**：通过性能落差与队列观察建立研究设置，同时分开数据贡献和融合方法的论证。

**肝脏分割失败检测 / Paper6055**：让“可靠”对应可观察、可判定的失败事件，改变论文的评价对象。

**OncoAgent / Paper5049**：把规则从固定预测映射中的隐含信息改为执行时可更新的条件，将适应过程纳入研究。

上述五例中四例是第一批案例的深度升级，另一个是新增分析对象；两个分析文件合计覆盖 **11 篇不同论文**，不是 15 篇。

## 这次精读特别修正了什么

已有实验不能再次被列作“应该补”的缺项：Paper6055 已有验证集阈值选择与区间报告；Paper5049 已有带 GTV 先验的比较模型和医生盲评。同时，零样本不等于整个流程无任何标注，共享/特异专家也不等于主次模态条件化。具体依据见精读册和证据清单。

## 使用与边界

当前主索引及 evidence.jsonl 是阅读深度的依据。第一批摘要笔记保留为历史分析；其中“尚未精读”的旧状态，应由新索引和新精读册解释，而非覆盖本轮证据。

所有新记录仍保持准确的实际读取范围。论文方法、训练代码和实验结果未独立复现，五篇完整引言核读也不等于全文审计。DOI、Oral/Spotlight 标签仍未逐条确认，不作推断。本文献集合是目的性样本，不用于统计会议总体趋势。
