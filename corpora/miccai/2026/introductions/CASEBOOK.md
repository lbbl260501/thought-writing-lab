## 1. FRODO：先给模态分工，再给网络分工

**来源**：[官方页](https://papers.miccai.org/miccai-2026/0002-Paper5533.html)；[PDF](https://papers.miccai.org/miccai-2026/paper/5533_paper.pdf)。定位：§1 pp.1–3。

### 段落推进

| 原文功能块 | 处理的对象 | 完成的叙事动作 | 为后文提供什么 |
|---|---|---|---|
| 临床问题块，pp.1–2 | 病灶及其影像证据 | 将临床相关性收束为病灶级分类 | 预测单位与输入条件 |
| 相关工作块，p.2 | 既有影像与建模路线 | 承认强比较对象，再定位剩余困难 | 方法需要优于什么，而非泛称现有方法不足 |
| 贡献块，pp.2–3 | QSM 与 FLAIR 的不同角色 | 从信息分工引出条件化建模 | 非对称结构的任务理由 |

**原文锚点。** 作者把 QSM 放在主要磁化率信号的位置，FLAIR 提供结构上下文；研究使用病灶中心的配准图像块，并结合预训练与对比正则。Tables 1–2 包含模型及训练策略比较，不是仅比较一个最终分数。官网 Reviewer #1 同时认可任务动机，并指出单中心验证的范围。

### 关键不是“双模态”，而是关系如何被定义

分析上，这篇引言可借鉴的操作是把一个并列名词短语改造成有方向的关系。写“QSM 和 FLAIR 提供互补信息”，只能解释为什么使用两个输入；写清谁承载目标证据、谁帮助解释目标证据，才开始解释为什么不采用对称处理。

这里有三个层级，仿写时应分开：**信息角色的差别 → 可检验的建模假设 → 某种网络实现**。第一层可以由成像知识支持；第二层要求控制实验；第三层只是候选实现。论证的力度来自把三层接起来，而不是把第一层直接写成第三层的证明。

### 句子工程：让客体成为下一句的主体

以下为原创表达示范，不是作者引文。

较弱：*The two modalities provide complementary information, and we design an asymmetric network to fuse them.*

更明确：*The observations support different parts of the classification decision. This division of roles motivates a test of directional conditioning against symmetric fusion.*

第一句的主体是 observations，动作是 support，客体是 decision 的不同部分；第二句接住这个 **division of roles**，动作改成 motivates，客体变成一个可比较的设计问题。第二句没有重复“互补性”，而是推进到“怎样检验分工”。

### 从引言返回证据

现有表格可以支持整体方案的比较，但其中对训练策略的消融，不能单独隔离“条件化方向”的作用。更强的后续研究可固定预训练、容量和数据，比较对称融合、两个条件化方向及单模态。这里是本库提出的判别实验，不是声称论文没有任何消融。

**可迁移操作。** 多模态研究先画出“观察—任务证据”的关系，再决定网络是否应当不对称。用于新任务时，不预设某模态永远更重要，还可以检验这种关系是否随病灶或采集质量变化。

## 2. 微波消融替代模型：把速度问题写成决策问题

**来源**：[官方页](https://papers.miccai.org/miccai-2026/0007-Paper4859.html)；[PDF](https://papers.miccai.org/miccai-2026/paper/4859_paper.pdf)。定位：§1 pp.1–2。

### 四步推进

| 功能单元 | 论证焦点 | 句间关系 |
|---|---|---|
| 第一段，pp.1–2 | 治疗结果依赖操作与患者条件 | 先列决定结果的变量，再指出简化工具遗漏什么 |
| 第二段，p.2 | 物理模拟能表达这些因素，但多次求解昂贵 | 已有能力与使用情境发生冲突 |
| 第三段，p.2 | 已有快速替代模型也有自己的适用范围 | 承认“快速预测”并非空白，重新定位增量 |
| 第四段，p.2 | 从预测器走向规划与再规划 | 方法的意义落在能完成的决策操作上 |

**原文锚点。** 作者将治疗参数与患者特异条件纳入快速正向预测，并把模型用于方案搜索。§3.1 分别报告模拟和动物实验层面的验证；p.8 的再规划评估使用已知消融结果及人工移动的天线位置恢复参数。它不等于已经完成患者术中前瞻性再规划试验。

### 最重要的转折：改变“计算一次”的计量单位

如果只写模拟很慢，贡献容易被读成一般加速。更有解释力的写法是先让读者看到一个决策必须反复比较候选方案，再说明单次代价如何限制可搜索范围。此时“快”不再是孤立指标，而是评价尚未实施方案的条件。

这是一种可迁移的叙事放大：**局部瓶颈 → 重复操作 → 系统能力**。它并不需要夸张技术新颖性，而是说明小环节改善为何改变整项工作的可行性。

### 句子工程：速度与价值之间补一个动作

原创示范：

较弱：*The simulator is computationally expensive. We therefore develop a fast neural surrogate.*

更明确：*Planning requires repeated evaluation of candidate interventions. The cost of each simulation therefore limits how extensively these candidates can be compared.*

这里的桥梁不是更多形容词，而是 **repeated evaluation**。下一段自然可以讨论近似模型需要保留哪些输入条件、哪些误差会影响候选排序，以及实际搜索能增加多少。

### 三种证据不要混成一个“有效”

| 引言承诺 | 该回答的问题 | 本轮精读后的判断 |
|---|---|---|
| 预测准确 | 输出是否逼近参考结果 | 原文有分层验证，而非只有训练分布内分数 |
| 规划可行 | 是否能在预算内搜索方案 | 原文将模型嵌入规划与再规划流程 |
| 决策可靠 | 近似误差会不会改变最终选中的动作 | 应继续以独立高保真评估检验候选排序和方案质量 |

用于新研究的判别实验是固定搜索器与目标函数，只更换正向模型，再分别控制时间预算和候选数量。这样能够区分“预测器近似得好”“搜索得更多”与“最终决策更好”。这比仅增加一个速度表更直接回应引言。

## 3. MA-MoE：先展示落差，再解释为什么需要新的研究设置

**来源**：[官方页](https://papers.miccai.org/miccai-2026/0012-Paper1806.html)；[PDF](https://papers.miccai.org/miccai-2026/paper/1806_paper.pdf)。定位：§1 pp.1–4，Fig.1 在 p.3，贡献段在 p.4。

### 引言的两条线

| 功能单元 | 本库功能标注 |
|---|---|
| 开头，pp.1–2 | 从临床联合观察进入计算模型的验证不足 |
| 异质性描述，p.2 | 把抽象“复杂性”展开成可观察的差别 |
| 性能落差与 Fig.1a | 将问题由判断变成需要解释的现象 |
| Fig.1b–d 的队列描述 | 为研究设置提供背景，而非直接识别因果 |
| 模型段，pp.2–3 | 引入共享与特异信息的组织原则 |
| 贡献段，p.4 | 分别交付数据设置、建模机制和实证比较 |

**原文锚点。** Fig.1 将公开数据与临床队列的表现差别放在方法介绍之前。主要验证是 B-mode 分别搭配三种补充模态。共享与特异专家由受限路由组织；这与 FRODO 的“一个主信号、一个条件信号”不是同一结构命题。官网 Reviewer #1 对跨域证据和解耦解释提出质疑，同时认可配对多模态任务与输入替换对照的价值。

### 先有观察，方法就不再凭空出现

这篇值得学习的地方，是不急于提出 MoE，而先给读者一个有待解释的性能落差。图在这里承担“建立研究对象”的功能，不只是为方法画流程。引言从而可以同时建立数据贡献和方法贡献。

但这两条线应分别闭合：**性能落差 → 新评价设置**；**信息互补 → 融合设计**。前一条并不自动推出后一条。写作上的改进方向不是删掉丰富背景，而是增加一个桥接命题，说明为何所选择的信息组织方式能缓解某一项明确困难。

### 句子工程：避免让一处转折承担五种解释

原创示范：

*The observed performance gap motivates evaluation across acquisition conditions. Within this setting, the modeling question is how to retain modality-specific evidence while sharing information relevant to the same decision.*

第一句承接“观察到了什么”，第二句限定“本文打算处理哪一部分”。这样的收束保留了临床复杂性，也避免读者误以为一个模块已经逐项解决所有异质性来源。

### 读引言时应继续追问的细节

受限路由可以作为明确的设计先验；若主张模型学出了共享或特异的语义内容，就需另加证据。比较输入替换、取消约束、可变专家比例及受控模态退化，可以分别测试信息来源、结构约束与可靠性适应。可视化是线索，但其解释强度不等同于这组判别实验。

对下一轮多模态研究，本例启发的不是照搬专家数量，而是将“模态身份”“信息共享程度”“样本可靠性”“计算分配”拆成不同研究对象，避免把它们统一叫作非对称性。

## 4. 真实失败检测：创新可以来自重新规定“什么算成功”

**来源**：[官方页](https://papers.miccai.org/miccai-2026/0017-Paper6055.html)；[PDF](https://papers.miccai.org/miccai-2026/paper/6055_paper.pdf)。定位：§1 p.2。

### 三段与贡献列表

| 顺序 | 功能 | 读者的判断发生什么变化 |
|---|---|---|
| 第一段 | 交代分割的下游用途 | 从影像输出看到操作后果 |
| 第二段 | 将失败与输入分布变化联系起来 | 从平均能力转向例外情况 |
| 第三段 | 指出真实工作流中的评价缺口 | 从“已有检测方法”转向“这些方法是否回答实际问题” |
| 两项贡献 | 真实部署评价与检测分数 | 同时交付研究设置和方法增量 |

**原文锚点。** p.3 以临床编辑需要和读者评分定义失败；测试标签由多名读者投票确定。p.5 说明阈值在验证集上选择，并报告不确定性。Table 3 的内部与外部失败数分别为 13 和 5。因此，“识别了观察到的失败”与“能保证识别未来所有失败”必须区分。

### 重新定义终点，比重复强调重要性更有效

本例的写作价值是把研究终点从“与参考轮廓接近”转为“哪些输出需要额外处理”。这不是换一个漂亮的指标名，而是重新安排标签、评价单位和使用场景。引言因此能够提出一个独立于骨干网络的问题。

分析时还应区分“输入陌生”和“输出不可接受”。前者可能是后者的风险因素，却不是同一标签。明确这种差别，会直接影响一篇论文应当验证什么。

### 句子工程：把形容词改成可观察事件

原创示范：

较弱：*Reliable segmentation is essential for clinical applications.*

更具体：*A useful failure detector should identify outputs that require substantial correction before use.*

第二句的优点不在于更强硬，而是给“可靠”指定了对象和判断行为。下一句可以自然接上谁来判定、何时判定和如何计算错误代价。

### 这次精读对旧案例的修正

旧案例把“固定阈值、报告置信区间”写成一般性建议；PDF 核读确认原文已经做了这两件事，不能再把它们列作缺失实验。进一步的审查应落在少量失败事件、读者差异以及不同统计方案对极端比例的区间估计上。

尤其在小样本且观察到全命中时，非参数重采样可能产生退化区间；这是一项统计复核问题，不是未来零漏检的证明。后续研究可同时报告事件数和适合比例参数的区间，再检验误报带来的复核负担。

## 5. OncoAgent：改变规则在系统中的位置

**来源**：[官方页](https://papers.miccai.org/miccai-2026/0009-Paper5049.html)；[PDF](https://papers.miccai.org/miccai-2026/paper/5049_paper.pdf)。定位：§1 pp.1–2。

### 信息释放的顺序

| 功能单元 | 叙事任务 |
|---|---|
| 临床与现有模型，pp.1–2 | 让勾画规则及规则更新成为问题的一部分 |
| Agent 概念段，p.2 | 先说明规则怎样转为操作，而非先报系统名 |
| 优势段，p.2 | 将标注需求、更新成本、可审查性设为不同评价轴 |
| 提案与贡献，p.2 | 将上述评价轴落实为研究交付 |

**原文锚点。** 方法利用指南、患者 GTV 轮廓和预训练 OAR 分割工具；“零样本”针对目标 CTV/PTV 任务训练，不是所有输入和工具都无标注。§3.1 包含同样使用 GTV 的比较模型及盲法医生评分。跨指南与前列腺扩展在 §3.4 / Table 3 主要用 Tool Call F1 评价，应与勾画质量区分。

### 真正的重新设问不是“能不能加入大模型”

本库把其问题重构概括为：规则应隐含在固定的预测映射中，还是成为执行时可更新、可检查的条件？这样写，Agent 才是实现某种计算关系的方式，而不是研究动机本身。

这个表达策略能保留方法的雄心，同时给它清晰的评价坐标。与其在总分不领先时反复辩护，不如从引言开始说明：研究比较的不只有轮廓精度，还包括规则变化之后的适应方式。这种坐标转换必须事先说清，并由对应实验兑现。

### 句子工程：用中间对象衔接规则与几何结果

原创示范：

*Guideline changes alter the constraints that a contour must satisfy. Representing these constraints as executable instructions makes the adaptation process itself available for evaluation.*

第一句的客体 constraints 成为第二句的主体。第二句再把“适应”从模糊优势变成可评价的过程。写作没有跳过指南到轮廓之间的中间对象，所以后面谈工具执行与医生复核不会突兀。

### 哪些主张应分别检验

规则解析、工具调用、生成轮廓和医生使用是相邻但不等价的终点。原文已经提供带 GTV 的较强基线和医生评分，不能建议“补一个同输入基线”而忽略已有证据。可以继续强化的是将跨指南评测从工具计划延伸到实际几何质量及工作流成本。

同样，“差异未达统计显著”不是等效性检验。对本类研究，更准确的贡献表述应结合实际效应与验证范围，而不是从小测试集的非显著结果推出全面等效。

## 6. 跨论文对照：不要复制同一种引言顺序

| 起点 | 本册案例 | 最关键的桥梁 | 贡献落点 |
|---|---|---|---|
| 不同观察承担不同作用 | FRODO | 信息角色如何影响建模关系 | 任务驱动的非对称设计 |
| 精细预测难以反复调用 | MWA 替代模型 | 单次代价如何限制候选比较 | 可执行的规划过程 |
| 基准表现与实际环境不一致 | MA-MoE | 现象、研究设置与模型问题分别闭合 | 数据设置与融合机制 |
| 平均表现不能识别不可用输出 | 失败检测 | 成功/失败如何操作化 | 更贴近用途的评价对象 |
| 规则改变而模型难以随之调整 | OncoAgent | 规则如何成为可执行条件 | 适应与审查的方式 |

以上是对五个文本的分析，不是 MICCAI 2026 的频率统计，也不是断言这些策略总能提升录用概率。

### 可以复用的三个精读测试

**删除测试。** 删去一个背景句后，后面的研究问题是否失去必要前提？若没有，考虑它只是礼节性铺垫，还是需要保留的读者定位。不要机械地把所有背景都删成口号。

**替换测试。** 把方法名称换成另一类网络，前面的论证是否完全不变？若不变，说明引言可能只论证了“应当改进”，还没有论证“应当改变哪种关系”。这不要求引言证明某一模块唯一正确，而要求提出可区分的原则。

**兑现测试。** 把每项贡献写成“在哪些条件下，改变哪个对象，用什么证据判断”。随后回到实验，不把已有实验再次列作缺项，也不把机制解释直接视为被总分证明。

### 迁移时可采用的工作顺序

先写研究对象与已知条件，再写读者需要接受的关键区别；选择一个能使该区别变得可观察的比较或反例；最后才选择相应的英语句式。语言动作服务于推理动作，而不是先选 however / therefore 再寻找内容。

完整论文的长引言可以多次往返这些步骤；短会议论文可以压缩为相邻句子。不能仅从本册篇幅推导 MIA、TMI、BSPC 的统一段数和字数规范。
