## 三层必须在同一个分析对象上相接

**宏观**：读者最终要接受什么主张？各章节分别承担哪一种证明责任？哪些承诺在后文兑现，哪些留作未来工作？

**中观**：一个段落进入时读者已知什么，离开时新增什么？主题句怎样设定问题，后续句怎样定义、解释、比较、提供证据或限定范围？图表之前提出什么阅读任务，之后解释什么意义？

**微观**：主体、动词与客体怎样组成可检验陈述？术语为何在这里出现？名词是研究对象还是把前文打包的概念？修饰语改变对象边界还是仅表示褒贬？从句、非谓语、介词、时态、语态与比较范围各起什么作用？

三层不是独立的三个栏目。以“condition”为例，词义与介词搭配要连到谁调节谁；这个方向要连到方法段的定义顺序；该定义又要连到全文的研究主张和实验。

## 分析对象覆盖整篇，而非把所有章节强塞进同一模板

题名看研究对象和限定范围；摘要看压缩；引言看需要与问题；方法看定义、步骤和理由；数据与实验设置看对象、划分和比较；结果看数字与关系；讨论看解释和替代解释；结论看回收与边界；图表及题注看脱离正文后的可读性；文献和声明看来源职责。原文没有独立Discussion的，不凭空造一个章节。

## 词汇与句子的标记方式

- **原文观察**：确实在所标稿件/章节中见到的词、词形或结构；基本词形不代表每次都以该词形出现。
- **原创分析**：本库对语义、段落功能、信息结构的解释；不是作者自述。
- **原创示范**：为学习而写的英语句子、搭配组合及段落；不是引文，不表示实验已经实施。
- **待核问题**：原文内部有疑点；不据此推断代码一定错误或作者的整个结论失效。

本轮没有全语料词频计算，也没有声称某种句式在MICCAI最常见。“两篇均出现”只说明局部复现；“建议积累”是教学选择，不是统计排名。以后只有给出样本、清洗口径、词形/词性处理、分母和分章节分布，才使用“高频”标签。
