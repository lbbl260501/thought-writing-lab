## 这不是另一套泛化标签

引言部分解释每段如何接住前文、改变比较对象、揭示前提、引出具体设计；必要句群进一步拆到主体、动作、客体和主张强度。讨论部分区分结果复述、机制解释、竞争解释、应用推论、局限和未来问题，并追回真实图表。原文没有独立 Discussion，就分析分散的讨论功能，不替作者发明章节。

分析不只找错误：DCTM从不一致结果推导模型选择，Locor承认新增灵活性的优化代价，CAMOS将当前输出安置到未来规划流程，都是值得实际模仿的叙述操作。原创英文句和新增实验均明确不是论文原文或作者已完成工作。
