# Public catalog exports

The **Master Catalog** lives in a private Google Sheet within the private Drive library. It maps stable IDs to books, papers, articles, concepts, thinking moves, exercises and typed knowledge relations.

This GitHub directory holds **only intentionally public, reviewed exports**. Keep private Drive file IDs, attachment URLs, Zotero SQLite files, permissions and personal information out of Git.

See [schema](../docs/SCHEMA.md) and [ingestion workflow](../docs/WORKFLOW.md).
