# Language foundations

Organize material by communicative function as well as formal grammar:
- `grammar/` — sentence structures, clauses, logical relations, reference.
- `vocabulary/` — semantic distinctions, collocations, lexical bundles, register.
- `discourse/` — information structure, paragraph coherence, narrative progression.
- `rhetoric/` — claims, concessions, framing, emphasis, stance and audience.

Grammar and vocabulary should be revisited through short writing tasks, not only as rules to memorize.
