## 本轮范围

12篇新增科研样本形成12张细读卡，另复核6篇旧MICCAI样本；3份方法学资料单列，未计入18篇科研样本。主要访问出版社HTML、作者版本和会议PDF。N07因正文抽取异常和PDF大小限制，仅可靠核读摘要。所有其他条目也按实际选读范围记录，没有全文审计或实验复现的声明。

原文摘录、中文上下文释读、本库分析、原创对照句分别标明；旧v0.1的24句仍是释写，不能据其统计原作者句法或词频。实际源版本优先于出版名气：读到arXiv作者稿，不等于读到了出版社最终稿。

## 分类的实质变化

主分类以叙事功能组织，另加论证关系、命题/证据、语言实现、信息推进与语境。主谓宾扩展为语法与语义角色；允许被动、系表、非谓语等结构；情态、条件和否定均检查其作用范围。

类别不是只增不减。新增、拆分、合并、降为属性、弃用映射以及暂不判定，都有适用条件。正例之外必须保留最近邻反例。所有类别目前都是待复核候选，不存在虚构的独立标注一致性或学习效果分数。

## 研究发现的检索入口

**改变问题，而非只改变网络：** N01贡献位置、N03评价依据、N04适用范围、N12迁移推论。

**精确说明差异：** N02目标属性、N06共享与独立、R04缺失模式、N10/R05不同可信性质。

**解释设计从何而来：** N08任务—模型—数据依赖、N09跨域类比的失效点、N11被忽略信号的用途。
