# 科学英语与叙事动作分类手册 v0.2

> C 组候选研究分类；Issue #4 / PR #21 的修订，不是中央分类表。版本 0.2.0，2026-10-14。分类是待检验的分析工具，不是写作成功的充分条件。

## 一、研究单位改变：从漂亮句子，到有上下文的命题动作

上一版24条案例是原创释写。它们可用于讲解，却不能代替原文来统计作者的语法、词频或句长。本版分别保存原文短摘录、上下文释读、语言分析和原创对照句。

最小分析单位采用可定位的**分句或命题跨度**，同时保留所属句子、段落及前后文。一个长句可以同时包含既有能力、剩余问题、目的和方法；不能为了单一标签抹掉内部关系。段落不是扩大版句子，而是多个动作的有序组合。

**一个主分类 + 五个独立描述维度：**

| 维度 | 回答的问题 | 不可混淆的对象 |
|---|---|---|
| F 叙事功能 | 此处说这件事，改变读者的什么认识？ | 问题定位、概念区分、重设评价、设计、证据、贡献 |
| R 论证关系 | 两个命题怎样连接？ | 对比、让步、条件、目的、支持；关系连接两个跨度 |
| E 命题与证据 | 谁提出何种主张，在何范围内成立？ | 作者/引用者/分析者；假设/结果/建议；来源核读与科学验证分别记录 |
| L 语言实现 | 哪种词汇、句法实现了这个动作？ | 语法主语与语义主体；谓语、宾语或补足语；情态、否定、语态、搭配 |
| I 信息推进 | 哪个信息被接续、突出或重新划分？ | 主题延续、新信息接力、对照焦点、上位问题拆解、段末出口 |
| C 语境 | 对谁、在论文哪里、为哪种写作任务而写？ | 体裁、章节、研究类型、实际阅读版本、读者知识前提 |

不要建立类似“however → 局限 → 不确定性 → 被动语态”的树：这些节点并不是同一分类维度。

## 二、与已有话语研究的关系

本版借鉴但不冒充复现三种不同的研究传统。

**Argumentative Zoning（AZ-II）**分析科研论证阶段、知识主张归属及与既有工作的关系。其修订将粗类拆细，并强调区分类别的具体规则和多标注者检验。我们采用“功能有边界、归属需明确、旧类可映射”的原则，而不宣称本库已达到其标注可靠性。核读：Teufel 等，2009，§1–3，尤其正文1494–1497页、Fig.2。[原始论文](https://aclanthology.org/D09-1155.pdf)

**Core Scientific Concepts（CoreSC）**区分假设、目标、方法、观察、结果、结论等科学内容；它回答的不是与 AZ 完全相同的问题。我们借鉴其内容角色分离，用于 E 维度，避免把作者目的当成已完成效果。核读：Liakata 等，2013，§2，正文748页对 CoreSC 的说明；本次未声称核读其2010年全部原始指南。[作者论文](https://aclanthology.org/D13-1070.pdf)

**PDTB 的关系标注与修订**关注分句间关系，说明新增材料可促使类别拆分、合并、转为属性，并需要把修改回迁旧标注。我们借鉴关系与功能分离、保留方向性及人工复核一对多映射的做法。核读：Prasad 等，2018，§1–3；不是声称直接采用最新版完整 PDTB 标准。[原始论文](https://aclanthology.org/W18-4710.pdf)

以下 F/R 标签均为本项目的**原创候选编码**。与上述体系的对应只能作为映射建议，不能直接合并成同义词。

## 三、主分类 F：8个动作家族、24个子类

表中的 N01–N12 指两份 CLOSE_READING 文档的新样本；R01–R06 指 AUDIT 中复核的旧样本。这里的支持是“存在可分析的文本案例”，不是“类别已独立验证”。

| 代码 | 动作与操作性定义 | 纳入标准 / 最近的排除项 | 当前文本锚点 |
|---|---|---|---|
| F1.1 TASK | 界定任务及其价值对象 | 说明处理什么、结果服务什么；空泛赞美不单独算有效任务界定 | N02引言开头 |
| F1.2 CREDIT | 承认既有能力 | 明确谁已做到什么；不把作者自己的新结果归这里 | N02、N04引言 |
| F2.1 RESOURCE | 定位资源约束 | 指出计算、标注、访问或工程成本；纯性能不足不是资源约束 | N05、R03 |
| F2.2 TRANSFER | 定位迁移障碍 | 源设定与目标设定的某种差异阻碍复用；仅说效果不好不足以区分 | N02、N09 |
| F2.3 RESIDUAL | 暴露剩余失败 | 承认已有进展后指出仍不满足的性质；与无条件全盘否定区分 | N10、R01 |
| F3.1 SETTING | 拆分问题设定 | 给出子情形及区分变量；随意列例子不等于分类 | R04客户端/样本缺失 |
| F3.2 CONSTRUCT | 区分科学概念 | 说明对象、定义或保证不同；近义词替换不属于此类 | N10与R05对照 |
| F3.3 MECHANISM | 分解候选解释或机制 | 把表面同一问题拆成不同作用因素；组件清单本身不够 | N09三方面分析 |
| F4.1 LOCUS | 改变贡献所在位置 | 从模块新颖性等旧焦点移到另一可研究对象；单纯提出方法不算 | N01配置体系 |
| F4.2 EVALUATION | 重设成功标准 | 由任务需求决定比较或评价维度；新增一个方便指标不自动成立 | N03 |
| F4.3 REVALUE | 重估信号的研究价值 | 把原本排除、忽略或低估的信号转为有条件利用的对象 | N11、R03 |
| F4.4 RANGE | 改变需要解释的适用范围 | 从局部任务/域内成功扩展到另一目标范围；一般说泛化好不算 | N04、N12 |
| F5.1 QUESTION | 提出可回答的问题 | 未知量或需要判断的关系可辨；问号不是充分条件 | N09、N12 |
| F5.2 HYPOTHESIS | 提出可被否定的假设 | 有暂定命题和适用条件；结果报告不能降格或伪装成假设 | N01 |
| F5.3 REQUIREMENT | 导出设计要求 | 说明为满足任务，方案需要具备什么性质；实现细节另标F6 | N03、N08 |
| F6.1 OPERATION | 描述具体操作 | 处理对象及变化可辨；高级、有效、创新等形容词不能代替操作 | N06、R02 |
| F6.2 ALLOCATION | 分配处理资源或权重 | 指明分给谁、按何依据、何时变化；普通先后流程不一定是分配 | N09、N11、R02 |
| F6.3 COUPLING | 组织部件间依赖 | 解释共享/独立/反馈如何相互制约；平行罗列模块不等于依赖 | N08、N06 |
| F7.1 REPORT | 报告观察或测得结果 | 说清观察对象和条件；机制归因需要F7.2 | N10、N12结果段 |
| F7.2 INTERPRET | 解释结果意味着什么 | 从观测到判断存在推理步骤；不能标成已独立证实的因果机制 | N07摘要、N12 |
| F7.3 COMPARISON | 建立有判别力的比较 | 比较什么、控制什么、区分何种解释；普通数值罗列不足 | N01结果讨论、N12 |
| F8.1 BOUND | 限定主张的范围 | 限定对象、条件、量词或迁移方向；礼貌性弱化不自动属于此类 | N12、R05 |
| F8.2 POSITION | 凝练贡献位置 | 将所做工作放回前述问题及比较轴；重复方法名称不够 | N01、N03 |
| F8.3 LIMITATION | 交代自身局限 | 明确当前工作未覆盖或难处理之处；他人方法局限归F2 | N02讨论局限 |

### 三组最容易误标的边界

**F2.2 与 F4.4：** 前者命名“旧方法为什么迁移受阻”，后者改变“本研究必须在哪个新范围内算成功”。同一段可以先前者后后者；不能据单个词 generalization 决定。

**F3.3 与 F6.3：** 分解“为什么可能存在这个问题”是机制分析；组织“本方法几个部件怎样相互制约”是设计依赖。MAE 的域间差异分析与其非对称实现不应被压成同一类。

**F7.1 与 F7.2：** 报告一次比较中发生了什么，不等于说明它为什么发生。需要模型归因、机制判断或超出观测范围的解释时，应保留第二层推理及其证据要求。

## 四、关系 R：不要用连接词代替逻辑

关系标注必须有两个定位跨度，分别写出内容摘要和方向。当前候选关系为：CONTRAST（同轴差异）、CONCESSION（承认前项但阻断常见预期）、CONDITION（条件）、PURPOSE（行动目的）、CAUSE_CLAIM（作者因果主张）、SUPPORT（证据/理由支持）、ELABORATION（展开）、INSTANCE（例示）、PARTITION（划分）、SUBSTITUTION（取代）、SEQUENCE（先后）、QUESTION_RESPONSE（问题—回应）。

这些不是 PDTB 标签的原样导入。CAUSE_CLAIM 尤其只表示作者在作因果陈述，并不表示本库确认了因果识别。

**诊断规则：**
- but/while 不总是让步。中立比较两个分支可以只是 CONTRAST。
- to + 动词常承载 PURPOSE，但要检查其句法位置；不能只见不定式便标目的。
- consequently/therefore 需要可复述的支持链。删除连接词后仍应能说明为什么后句跟随前句。
- 一对跨度允许显式和隐式关系并存，但分别说明文本依据；不为凑复杂度叠标签。
- 原文没有支持的桥接推理可以单列为分析者重构，不能伪装成作者句间关系。

## 五、E：力度、归属、证据分别记录

至少记录：**主张归属、命题类型、适用范围、比较对象、否定/情态作用域、支持材料位置、实际核读范围**。

命题类型可选：背景陈述、假设、研究目标、设计描述、作者报告结果、作者解释、规范性建议、自身局限。归属可选：当前论文作者、被引研究、审稿人、本库分析者。来源访问状态与实验验证状态绝不可合并：看见结果表不等于复现结果。

不要建立 suggest < show < demonstrate 的机械打分。动词力度取决于它承诺的**对象**。展示一个工作流与证明临床安全，不会因为都用了 demonstrate 而具有同样证据要求。N03中的规范性建议可以语气坚定；N12中的否定情态精确限制推论，并非作者不敢下结论。

**修辞目标不是处处降调。** 有依据时应明确提出问题、选择评价坐标、突出优势；要防止的是在改写中悄悄改变对象、条件或量词。

## 六、L与I：由主谓宾扩展到语义—句法—焦点

### L：每条原文至少看五项

1. **语法结构**：完整分句、被动结构、系表结构、非谓语结构或疑问句。不是所有句子都有宾语。
2. **语义角色**：研究者、模型、数据、指标、操作或证据分别扮演什么角色。语法主语不总是施事。
3. **谓词与补足内容**：具体操作、状态、关系、认知/报告行为。宾语、表语、介词补足语分别写。
4. **范围装置**：条件从句、情态、否定、程度与比较修饰。特别检查修饰哪一个部件或命题。
5. **搭配与信息重心**：某科学动词通常需要何种对象、句子把新内容放在哪里。记录真实实例，暂不根据少量例子声称高频。

例：N06的权重是被动结构中被保持独立的对象，不是自主执行设计的行动者；N10的校准描述是性质判断，不应硬填一个宾语。

### I：信息推进不是“每句宾语都变成下句主语”

当前记录五种模式：持续展开同一主题；上句新信息成为下句话题；对照两种对象/条件；将上位问题拆成子问题；把段末未解要求交给下一段。还要注明每句的**不可替代新增信息**。

若删掉某句后，问题、证据和论证出口都未改变，它可能只是衔接装饰；但必要的背景或概念界定不能因“不够新”就机械删除。

## 七、C：跨体裁比较的边界

本批主要是医学影像与机器学习，另有地球系统预测作为域外对照。取样是为了发现不同动作，不是随机估计期刊频率；不能由一篇 BSPC 与一篇 TMI 总结两个期刊的固定文风。

区分出版身份与实际读到的文字版本：标注作者手稿时，不能称其句法就是出版社最终版。N01的手稿标题与正式期刊标题不同；N07本轮只能可靠核读摘要。未有考试真题写作语料，故考试迁移只可作为待测试任务，不能当成已经建立的跨体裁结论。

## 八、可持续修订：定义稳定，标签允许改变

每个类别应维护：代码、中文定义、纳入/排除条件、正例、最近邻反例、证据源、争议、版本及状态。当前全部为 **provisional**，没有独立复标一致性结果。

- **新增**：确实出现现有定义无法表达、且会改变写作判断的差异，才提新类。只换了一个连接词不够。
- **拆分**：旧类包含两种不同操作，且能给出可重复的判别规则；保留父类，记录旧记录迁移。
- **合并**：不同名字长期指向同一行为，或边界对写作指导无用，保留别名并合并。
- **降为属性**：差异只涉及语态、所有权、情态等，转到独立维度，避免主分类膨胀。
- **保留不确定**：允许 OTHER、UNRESOLVED、一个主类加一个有依据的次类；不强行给每句唯一答案。
- **弃用不删除**：旧代码保留到新代码的映射；一对多变化逐条复核，不全库字符串替换。

训练分类规则的样本与评估规则的样本应按**论文**分开。同一论文十个句子不是十份独立文献证据。报告源论文数、研究类型和核读范围，再报告句段数。
