# Thought Writing Lab · 思想与科学写作实验室

一个长期建设的跨学科知识库与英语写作训练项目：以**英语语法、词汇、语篇、叙事和修辞**为语言基础，以**科学论证、研究问题、理论构建和论文写作**为高级应用，借鉴哲学、文学、电影、数学、认知科学、控制论、设计学等领域的可迁移思想方法。

> 核心目标：不只积累写作模板，而是建立能够反复练习、迁移和改进的 **thinking moves × writing moves** 体系。

## 项目边界与存储

- **GitHub**：原创笔记、概念定义、思想方法、练习、教材源文件、公开引用信息和版本历史。
- **Google Drive（个人、私有）**：书籍、论文、文章的原始附件和扫描件。实际文件 ID 与权限只保存在私有索引中。
- **Zotero**：引文元数据、DOI/ISBN、阅读标注、引用键。
- **Google Sheets Master Catalog（个人、私有）**：稳定资料 ID、附件位置、阅读状态、概念关联及练习映射。

在公开仓库中**不保存**未经许可的商业电子书、出版商 PDF、个人文件链接、私人笔记、访问令牌、Zotero 数据库文件。

## 学习路线

1. **Language** — grammar, vocabulary, syntax, semantics, discourse, rhetoric。
2. **Thinking** — observation, conceptualization, inference, framing, design, persuasion, revision。
3. **Scientific inquiry** — research question, competing hypotheses, formalization, experimental design, evidence and contribution。
4. **Writing practice** — 四六级/考研/雅思/托福的句段练习，以及论文引言、叙事链、论证链、理论构建工作坊。

课程结构允许交叉进入，**不要求先学完英语语法才能开始科研写作**。

## 开始使用

1. 新资料先进入私有 Drive 的 `00-Inbox`，再记录到 Master Catalog。
2. 按 `BOOK-000001`、`PAPER-000001`、`ART-000001` 编号；编号一经使用不复用。
3. 将资料转成有来源依据的原创卡片，并建立从思想方法到写作练习的关联。
4. 编写讲义时，把学习者正文与编辑过程、验证数据和项目管理分离。
