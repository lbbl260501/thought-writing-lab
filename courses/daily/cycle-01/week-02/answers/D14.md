# D14 · 第二周独立迁移的答案、判分与后续决策

**不要把本页示范改写成自己的第一次作答。**本课为原创假设情境。示范展示可接受的推理过程，不是唯一答案；学生的实际能力必须依据**未见提示的作品**判断。

## 第一部分：闭卷六项的最低解释标准

1. **定义（D08）**：概念层说研究关心什么，操作层给出具体可重复测量和指标。将 FLOPs 直接定义成“实时性”会混淆代理指标和端到端性能。
2. **比较（D09）**：与谁比较、按什么指标、在哪些条件、变化幅度多少；最好再报告差异不确定性和公平性。
3. **论证（D10）**：Claim 是主张，Ground 是可核查依据，Warrant 是从依据推出主张所需的前提与推理；单一相关或性能数字通常不能证明机制。
4. **语气（D11）**：已观测数字应明确报告；*may reflect* 适合描述竞争解释尚存的机制推测，不能模糊实测值。
5. **综合（D12）**：按研究问题组织策略、评价对象和未测关系，能让读者理解为何提出新问题。
6. **定位（D13）**：可以调整叙事起点和强调力度，但不能改动测量值、比较条件、结论强度或遮蔽会导致实质性误解的重要结果。

**常见假掌握**：能背“主张—证据—依据”，却找不出具体论文句子的隐藏 Warrant。

## 第二部分：句群修复

**A** 混淆理论操作量与实际时间：
> We quantify computational demand using FLOPs, while real-time performance requires a separate end-to-end latency criterion under specified hardware and workflow conditions.

**B** 把单城市结果推广到所有城市：
> Model B achieved a lower prediction error in the evaluated city, but its performance in other cities remains untested.

**C** 把更低误差当作“理解每栋楼需要什么”的机制证明：
> The lower error motivates testing whether adaptive weighting exploits building-specific information rather than benefiting mainly from greater model capacity.

**D** 是逐篇报菜名，不能出现一条研究问题。可改为：
> Work on sensor-based prediction examines how signals are combined, how their usefulness varies across conditions, and how computation is allocated. A remaining question is whether those decisions can be adapted under matched resource budgets.

**E** 忽略第三部分题设中 B 计算量增加：
> Model B reduced average prediction error on the evaluated dataset but required more estimated operations; its suitability for compute-constrained use remains uncertain.

强结论分别需要实测时延、跨城市数据、容量匹配消融、原始论文核验或匹配预算对比等证据。不要只把强动词替换为 *may* 而维持原先的错误解释。

## 第三部分：主题 X 的示范学术段落

> Reliable building-energy forecasts can support planning, yet their quality depends on how models use weather and occupancy observations. In this hypothetical evaluation, fixed fusion and adaptive weighting were compared on the same 50 buildings in one city. The adaptive model reduced mean absolute prediction error from 14.0 to 12.8 kWh per day, while estimated computation increased from 40 to 70 GFLOPs per prediction. This observation establishes a within-dataset accuracy–computation trade-off, not a general improvement in operational efficiency. Adaptive weighting might accommodate differences among buildings, but additional model capacity and computation offer competing explanations. Comparisons against fixed and random weighting at matched budgets, repeated across runs and held-out buildings, could help distinguish these possibilities. Future evaluations should report error by building type and season, alongside measured latency and memory use on intended hardware. A lower overall error could also conceal whether gains are concentrated in a small subset of buildings. Such evidence would clarify when condition-dependent sensor use merits its computational cost.

这段的关键不是“有五个段落动作”，而是**每个动作都改变读者对研究问题的理解**：任务对象 → 可信观察 → 取舍关系 → 竞争机制 → 判别实验 → 决策价值。

### 主题 Y 的另一种可接受论证骨架

完整独立段落可以从“参与度的定义”切入：线上提醒前后出席率为 58%/63%，但两期群体组成不同，也无随机对照。**出席率不是学习效果**；群体变化和其他同期活动也可能解释差异。进一步的试验可把提醒策略随机分配给可比较的活动参与者，预注册“实际到场”的指标，之后单独测试阅读或长期参与。政策建议可以是“值得小规模受控评估”，但不能写成“已证明公共教育显著改善”。优质回答会明确区分统计显著、社会价值与因果效应三件事。

## 第四部分：模拟相关工作的示范

> In the hypothetical research set, studies of sensor-based prediction address distinct questions. Study I evaluates how complete inputs can be combined, whereas study II tests performance when some signals are unavailable. Study III instead compares resource-allocation policies under matched budgets. These studies cannot be ranked using one accuracy number because their evaluation conditions differ. A further question is whether estimates of condition-dependent sensor value can improve budgeted prediction without creating new vulnerabilities when inputs are missing.

这段有分类、对照评价条件和新问题，而不是仅把 I–III 三份摘要连起来。

## 第五部分：四维评价的可操作锚点

以下为**本课程启发式量表**，不是经过标准化测量验证的心理测验。每项独立判断，0–4 不能混成一个“流畅度总分”。

| 分值 | Accuracy / Clarity | Scientific reasoning | Transfer |
| --- | --- | --- | --- |
| 0 | 多处无法识别意思 | 未形成可辨认主张 | 不能独立构建回答 |
| 1 | 语言或衔接造成关键误读 | 明显把数据当作机制证明 | 只重复课上范例而误用事实 |
| 2 | 基本可理解，有重要含混 | 能发现部分证据缺口，实验对照仍不充分 | 迁移出框架但漏掉关键条件 |
| 3 | 主要意思准确，句间推进明确 | 有可检验主张、合理限定与主要对照 | 新领域可独立搭起完整链条 |
| 4 | 术语与结构精确，能解释选择 | 能识别竞争解释、失败结果和边界 | 无提示迁移且能主动纠正隐含假设 |

**不同维度可以有不同得分。**一篇语法精美却因果推断失真的短文不能高分通过 scientific reasoning。

## 使用本次诊断安排下一轮

- 概念空泛、效率与时延混同 → 回 D08/D09，换一组新数据独立定义与比较。
- 报告数值没问题，机制解释过强 → 回 D10/D11，写 Warrant 与反例。
- 相关工作仅按研究名称串接 → 回 D12，先画问题地图再写。
- 为迎合受众而掩盖重要不利证据 → 回 D13，训练多种有根据的定位。
- 完整通过仍不表示长期掌握；选择未见过的主题，做延迟再测并比较**真实原稿与修订稿**。
