# Week 02 · 从准确句段到有证据的科学论证

第一周练习了“句子实际声称什么”；第二周要回答另一个问题：**怎样让读者知道你的概念可测量、比较有共同标准、结论有证据支持？**

**用时选择**：标准学习约 60 分钟（检索 10、讲解 12、小练习 15、研究迁移 18、复盘 5）；忙碌日可只用 20 分钟做检索、核心微练和修订，但未做研究迁移时不要将全课记作已完成；深度学习可增加 30 分钟英文扩写或交叉对比。

**材料性质**：本周的科学背景、数据表与“研究 A/B/C”等均为**原创假设情境或虚构教学研究**，不代表已发表论文的结论。真实论文语料待研究组提交核验定位后再增补，不能把虚构材料填进正式引用表。请把本人作文、评分、错误记录放在私有学习记录中，不要提交到公开仓库。

**复习提示**：D08 重取 D05 的“问题边界”；D10 无提示重做 D08 的定义题；D12 重做 D09 的一项比较；D14 综合抽测 D01–D13。对于关键失误，应在随后第 1、3、7、14 个**实际学习日**用全新材料再次检索，按表现灵活调整。
