# D14 · 第二周无提示迁移：你的论证离开范例还能成立吗？

**今天没有新知识，也没有写作模板。**先关闭 D08–D13 讲义，在陌生材料里独立完成定义、比较、证据桥梁、结论限定、文献组织与受众定位。只有完成初稿、保存后才打开 [答案与评分指引](answers/D14.md)。

**建议用时：60–75 分钟。**这是一项训练用诊断，而非经过标准化验证的考试。你可以记录实际耗时，但不要从练习完成自动推断已经掌握。如果上一周 D07 未完成，请将本课视为试做，并保留真实难点以便调整学习顺序。

## 第一部分｜闭卷概念重取（8–10 分钟）

不看资料，用自己的中文或英文完成六项，每项最多两句：

1. **D08**：概念定义与操作定义怎样不同？举一个会误导结论的替换。
2. **D09**：一句“模型 B 更好”必须至少问哪四个比较条件？
3. **D10**：Claim、Ground、Warrant 各是什么？为什么数据不能自动生成 Warrant？
4. **D11**：什么情况下应直接说 *achieved*，什么情况下应说 *may reflect*？
5. **D12**：文献分类为什么要围绕问题，而不是题名或年份？
6. **D13**：叙事可以改变信息重点，但哪些科学事实不能改变？

**不要先开答案找关键词。**若只会记定义，而说不出例子，这正是本次诊断要发现的情况。

## 第二部分｜句群修复（10–12 分钟）

以下五句话都来自虚构作者草稿。各写出问题类型，再改成可以用来继续研究的句子或句群。允许增加未知条件，但不得编造新数据。

A. > We define real-time execution as requiring 30% fewer FLOPs.

B. > Since model B is more accurate in one city, it performs better in all cities.

C. > Adaptive weighting learned the actual energy requirements of each building because its prediction error was lower.

D. > Study I did sensor fusion. Study II did seasonal analysis. Study III optimized models. Therefore, we propose a revolutionary framework.

E. > For users with tight computing budgets, model B is superior because it requires no additional computation.

先写英文修订，再用中文说出需要什么额外证据，才能把相应主张写得更强。

## 第三部分｜独立写一段 150–180 词的研究文字（22–25 分钟）

从下面两个**原创假想情境**选一个。两者都不是已发表研究的事实报告。你必须在不查阅本周示范段落的情况下完成。

### 主题 X · 建筑能耗预测与传感器选择

一个城市中 50 栋建筑的同一评测集，两个模型均使用气象数据和室内占用传感器：

| 教学模型 | 输入融合方式 | 平均绝对预测误差 | 标称每次预测计算量 |
| --- | --- | --- | --- |
| A | 固定融合 | 14.0 kWh/天 | 40 GFLOPs |
| B | 条件化加权 | 12.8 kWh/天 | 70 GFLOPs |

未进行重复随机实验、外部城市评估、端到端延迟评测。也未控制全部模型容量差异。

### 主题 Y · 公共图书馆活动与“参与度”

某公共图书馆试点了线上提醒功能，记录的活动出席率从 58% 升至 63%。两期参与群体年龄结构有所变化，没有随机对照，也没有阅读能力或长期参与测验。有人宣称“数字化提醒显著提升公共教育效果”。

### 写作要求（选 X 或 Y，一段 150–180 英文词）

你的段落应该让一个**尚未知道题设的学术读者**理解：

- 研究问题和需要定义的关键概念是什么（例如“预测质量”或“教育参与度”）？
- 已观察的数字是什么，在何种条件下比较？
- 从观察走向较强解释需要什么 Warrant；至少一个竞争解释是什么？
- 下一项能够区分解释的实验如何设计？
- 结尾对选定读者（领域科研人员或实践决策者）提出什么有证据边界的研究价值？

**不可使用** *revolutionary, guarantees, proves universal superiority* 或未观察的临床/教育效果。你可以正面突出有利证据，但不能抹去不利事实或改变度量含义。

## 第四部分｜假想文献拼接（8–10 分钟）

以下 I–III 是**虚构学习卡**，不能作为真实文献引用。

- I：在完整传感器输入下比较固定融合与直接拼接；
- II：在传感器丢失条件下训练和评价模型；
- III：在同一预算内比较固定路由与按输入条件化路由。

请在**60–85 个英文词**中，把 I–III 组织为一段相关工作，中心问题设为：

> Under what conditions should a predictive model change how it uses available sensor information?

至少有一个连接句说明各研究的评价对象为什么不同，并以一个**尚未有证据充分回答的问题**结尾。不能简单顺序罗列三项研究。

## 第五部分｜修改与评分（10 分钟）

先封存第一版，再按四个独立维度各给暂定 0–4 分并**写出证据**：

| 维度 | 问自己什么 |
| --- | --- |
| Accuracy | 术语、数据、逻辑主语与英文表达是否准确？ |
| Clarity | 句间信息是否真实前进，而非全靠连接词？ |
| Scientific reasoning | Claim 是否超出 Ground；Warrant 和对照是否成立？ |
| Transfer | 是否独立解决了陌生问题，而非移植 PET/CT 模板？ |

**至少修订两处不同性质的错误**：一处与语言或信息流有关，一处与科学论证有关。记录“原句→改写→修订理由”；保留原稿，不要让 AI 直接覆盖。

## 何时进入第三周？

如果你能独立完成第三部分，并说清每个结论的证据条件，可进入 D15 的引言任务价值构建。若定义和比较仍不清晰，先针对 D08/D09 设计一题新情境；若段落能写但论证桥梁断裂，回练 D10/D11。相关工作若仍是流水账，复习 D12；有“不同受众就不同结论”的倾向，回练 D13。

**延迟复核**：间隔若干实际学习日后，在不看修订稿的情况下尝试**另一个主题**，比较是否仍犯同一种错误。结果必须来自你的实际作答，不能从完成课程文件推算。
