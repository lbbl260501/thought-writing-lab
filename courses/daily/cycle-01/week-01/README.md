# Week 01 · 科学思想如何成为清晰的英文句段

**目标**：把“有一个大概意思”发展成“读者能准确理解、能判断其证据条件、能沿着句子推进的问题”。

| Day | 主题 | 可见成果 | 答案/讲解 |
| --- | --- | --- | --- |
| [D01](D01.md) | 科学主体、动作与客体 | 两个精确句子、一个研究问题 | [解释](answers/D01.md) |
| [D02](D02.md) | 科学动词与证据等级 | 三个不同强度的论述 | [解释](answers/D02.md) |
| [D03](D03.md) | 新旧信息与句群 | 四句连贯科学论述 | [解释](answers/D03.md) |
| [D04](D04.md) | 相关和因果 | 竞争解释与识别实验 | [解释](answers/D04.md) |
| [D05](D05.md) | 让步、对照与问题张力 | 一个研究 gap 段落 | [解释](answers/D05.md) |
| [D06](D06.md) | 五句的科学段落 | 100–130 词写作 | [解释](answers/D06.md) |
| [D07](D07.md) | 闭卷迁移测试 | 陌生题材下的短文与论证 | [评分指引](answers/D07.md) |

**用法**：先读当天课程并独立写出答案，再打开对应解释。可以用考试题训练短句与段落，但不把科研论证简化为考试模板。

**建议检索**：完成 D02 时闭卷重做 D01 一小题，D04 时复习 D01/D02，D07 时综合重构 D01–D06。实际复习频率根据错误记录调整。

本周示例均为原创教学情境，除专门标明的论文链接外，不是来自论文的原句。专业事实不代替个体诊断或临床判断。
