# D07 · 第一周迁移测验：让方法离开熟悉例子

**今天不是学习新知识，而是检验你是否真正掌握了前六天的操作。**先关闭所有讲义，至少完成 A 与 B，再看 [评分指引](answers/D07.md)。

## 1. 10 分钟闭卷检索

不用材料，独立写出：
1. 科学句子的四个基本元素是什么？为什么“语法正确”还不能保证科学表达准确？
2. `predict` 与 `explain`、`associate` 与 `cause` 的差别是什么？
3. 为什么 `although`、`whereas` 和 `however` 不能无条件替换？
4. 你怎样判断一个段落的四句之间是否存在真正的信息推进？
5. 把“一个现有方法的缺陷”发展成可检验科学问题需要哪些步骤？

写完后再回忆 Day01–Day06 中哪一道题改变了你原来的理解。

## 2. 混合语言训练：完全新题（12–15 分钟）

**虚构情境：** 一项森林遥感变化检测模型，在不同季节拍摄的图像间出现较多误报。开发者加入时序条件化模块后，某测试集误报率下降，但目前不能确定改进是否来自模块设计，还是因为训练数据增加。

以下三句各有不同问题，请修正，再写出问题类型：

A. `The model understands seasonal changes and therefore guarantees accurate forest monitoring.`

B. `Although the model reduces false positives, it may improve reliability in changing seasons.`

C. `Different seasons are challenging. The model does well. This is very important.`

要检查：A 的论证强度，B 的让步关系是否真的存在对立，C 的信息承接与科学对象精度。

## 3. 完整迁移：120–150 词研究引言段（20 分钟）

选下面任一主题，**不能照搬 PET/CT 段落，只可以迁移方法**：

- **题材 X：遥感伪变化检测**。现有变化检测能识别时相差异，但季节、照明和成像条件会影响观察，某些表观变化不代表真实地表变化。
- **题材 Y：教育科技**。AI 写作辅助可以改善部分作文的即时形式质量，但作者独立构建论证与修订的能力需要另行评价。

段落需要：
1. 具体任务及已有能力；
2. 一个清晰的条件或假设差异；
3. 为何现有评价未能自动回答你的问题；
4. 一个可以用实验比较的研究问题；
5. 在措辞中保留主张强度与证据的界限。

## 4. 自我审查（8 分钟）

使用四维 0–4 的评价表自行给出**带理由的暂定判断**（不需要凑成满分）：
- 英语准确性：是否有语法和语义偏差？
- 信息清晰性：读者能否无障碍识别句群主题推进？
- 科学论证：每个科学结论的依据是什么？
- 迁移性：是否真正把方法用在新场景，而不是复述前六天的术语？

**必须保留第一次原稿**，再修订，并写出最重要的两个错误。如果问题出现在概念层，就补科学解释；如果出现在信息流，就练句群；不要只要求 AI 将句子润色得更复杂。
