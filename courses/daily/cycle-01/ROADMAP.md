# Cycle 01 · 28 个学习日：从清晰表达走向科学问题与引言

目标：经过四周螺旋训练，学习者不仅能够写出准确英语句段，还能够在有证据约束的条件下独立构造研究问题、选择论证框架，并完成短篇引言。**这不是 28 天后自动达到某个等级的承诺**；难度和轮次应根据真实答案调整。

## 学习依赖与动态调整

首周重点依赖关系：D01 科学陈述 → D02 证据强度 → D03 信息衔接 → D04 因果/预测界限 → D05 科学张力 → D06 段落构建 → D07 盲测。

不必把“语法学完”作为进入研究写作的前提。最晚从第一天起就练习问题构造，只是深度逐渐增加。

推荐规则：未能独立完成关键概念的闭卷迁移，下一学习日先安排同能力的替代题，而不是机械跳到更高级章节。允许跳级，但应保留诊断记录和相应的盲测。

本路线 60 分钟/天只是初始教学配比；依据实际完成情况和精力变化进行调整。
