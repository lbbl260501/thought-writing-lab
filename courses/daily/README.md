# Daily Writing & Thinking Studio · 每日英语表达与科学思维

这是 **Thought Writing Lab 面向学习者的实际训练课程**，与语料抽取、编辑档案分离。读者可以按 **Day 0 → Day 1 → ...** 自行学习；**Day 是学习序号，不是日历日期**。漏学、出差或研究繁忙时停在当前 Day，下一次继续完成它，不需要补进度表。

**第一轮不是“每天背完若干句型”**：一项思想和写作动作依次出现在词/句、段落、跨体裁和真实科学研究中。每一天都要求**独立写作、分析语言选择、形成可复查的输出**。

## 每日训练：60 分钟建议配置

| 环节 | 时间 | 如何学习 |
| --- | ---: | --- |
| 闭卷检索、复习旧动作 | 10 min | 写出旧知识/改写旧句；再核对，不先看答案 |
| 新知识解释与对照例句 | 12 min | 先理解本日一个关键机制，比较正反表达 |
| 微训练 | 15 min | 在句子/句群/段落中主动使用这个机制 |
| 科研或跨体裁迁移 | 18 min | 完成新问题定义、论证、实验构建等任务 |
| 自检、修订与错误记录 | 5 min | 保存草稿、修订稿、下一次闭卷检索问题 |

**20 分钟轻量模式**：3 分钟检索 + 5 分钟学习要点 + 8 分钟当日一项微训练 + 4 分钟修订。未做完的研究任务标为待完成，不能声称整课已经完成。

**90 分钟深度模式**：标准课 + 30 分钟增加阅读案例、独立写作、与新领域比较。延长时长不意味着更高分数。

## 能力评价

按 4 项各 0–4 分：**准确性（grammar/semantics）**、**清晰性（information structure）**、**科学推理（claim/evidence）**、**迁移能力（unseen application）**。

- 0：不能独立完成；1：有关键缺陷；2：基本可理解但有明显缺口；3：可靠完成大部分要求；4：能准确论证选择并迁移到新问题。
- 不要求每天四项全满；对不涉及推理的微题可以只评相关指标。
- 评分不是为了打卡，而是决定下一次复习的重点。

## 复习、答案与隐私

初始建议在本课完成后的 **第 1、3、7、14 个学习日**做短暂闭卷检索；间隔是课程设计的可调启发式，不是学习科学保证的最优间隔。出现遗忘可提前复习，达到熟练则延长。

**先提交自己写的答案，再打开每一天的 `answers/Dxx.md`。**答案是分析与参考版本，不是唯一的合法句子。所有学生自己的原稿、错题和评分应当保存在私有学习日志，不应进入这个公开 GitHub 仓库。
