# MICCAI 科研思维与英语写作工作坊

从 [MICCAI 2025–2026 官方论文语料](../../corpora/miccai/) 提取具有来源追溯的研究和写作动作，面向科研工作者的英语表达与研究思维训练。

## 教学原则
- 阅读顺序可以从研究问题、段落、句法任一入口开始，最终连接到科学验证。
- 每讲同时拥有“现象与科学问题”“原文动作分析”“英语精读”“小练习”“科研大练习”五种材料，但不需要机械均分篇幅。
- **语言风格优劣、科学贡献优劣、评审结果是三个不同评价对象。**
- 保持学生正文与语料元数据、编辑审计资料分离。学生教材不得退化为抓取报告。

## 课程规划
1. **From Challenge Lists to Researchable Questions** — C²MAOT 的挑战分解与审稿新颖性质疑。
2. **Reversing the Research Workflow** — CAMOS 中从骨驱动到软组织目标预测的问题转换。
3. **Changing an Assumption Changes the Problem** — Locor 与 MMA-LTS 的尺度和模态身份问题。
4. **Asymmetry as a Design Choice vs Task Property** — CDFP-Net 的 PET 锚点与可学习任务非对称性的区别。
