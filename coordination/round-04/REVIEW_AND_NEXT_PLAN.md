## 四、A–F建议拆分

| 单元 | 主产物 | 最小验收 |
|---|---|---|
| A1 来源与版本 | 来源身份、版本、许可、读取深度 | 两篇来源全字段可回查 |
| A2 文本定位 | 引言/讨论句群、图表位置 | 两篇定位可回原文 |
| B1 论文精析 | 问题—前提—设计—检验—结论链 | 两张全篇卡及跨文对照 |
| B2 书籍原则 | 原则、适用条件、反例 | 一项原则连接两种论文情境 |
| C1 语言与句法 | 分句跨度、语义角色、范围和衔接 | 10个可定位分句 |
| C2 叙事与篇章 | 段落动作序列与信息接续 | 3组段落，说明每句独有信息 |
| D1 科学问题 | 未知量、单位、默认假设、目标 | 3张问题卡和一个反例 |
| D2 判别实验 | 竞争解释—干预—固定项—结果 | 3张实验格，明确结果怎样改变判断 |
| E 跨域机制 | 原问题、可迁移操作、失效条件 | 每条机制有边界或反例 |
| F 学习者课程 | 讲解、独立小题、答案、迁移题 | 题目可独立完成，答案可解释选择 |
| Q/HQ审核 | 独立审查与发布决定 | 来源、科学、语言、教学、工程五道门 |

不建议按年份把A/B永久固化。年份应是采样维度；长期职责更适合A做来源接入与定位、B做跨论文精析及书籍原则。C判断怎样表达，D判断证据允许说到哪里；二者应并行而互相约束。E要提供机制与失效条件。F是应用端，不负责上游事实发现。
