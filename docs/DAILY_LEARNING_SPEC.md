# Daily Writing & Thinking Studio · 长期课程设计与质量规范（编辑者专用）

## 1. 定位

**日课是 Thought Writing Lab 的学习应用端，不是素材库管理功能。**根路径 `courses/daily/` 面向学习者，私人作文与反馈则只保存在个人 Drive 日志。课程制作者不得修改私有学习结果。

长期 Program [#12](https://github.com/lbbl260501/thought-writing-lab/issues/12) 与教材研究 [#11](https://github.com/lbbl260501/thought-writing-lab/issues/11) 协作：#11 研究教什么、怎样评价教材，#12 研究学员每天如何练和怎样持续成长。

## 2. 每个学习日的必要内容

- **真实写作困难**：避免用抽象术语当开头；要让学习者知道它为何影响实际表达。
- **概念解释与对照**：语法形式 + 语义差别 + 科学动作；最好包括一个不够理想的写法与分析。
- **微训练**：独立可完成的英语练习，不是仅要求“思考”；必要时限制词数和科学语境。
- **科研迁移**：把同一思维动作迁移到新的实验、论文或研究问题；必要时包含基本变量和对照。
- **跨体裁或跨领域**：周期内覆盖四六级/考研/IELTS/TOEFL/科学研究及医学以外语境；具体题型依用户需求，不假定考试最新题型。
- **解释型答案**：答案独立文件，并说明何种措辞改变了语义，哪些答案也合理。
- **学习检查**：给出能够证伪“我以为学会了”的独立检索/迁移任务。

学习者文档须流畅、有教学经验，不要包含 GitHub 操作、作者状态、私有数据库字段、过长技术报告。编辑说明和引用审计放 `docs/`。

## 3. 推荐节奏与弹性

Standard 60 min: 10 retrieval + 12 new explanation + 15 micro writing + 18 research/transfer + 5 reflection. Quick 20 min and deep 90 min are备选，**不据称是经过实验比较得出的唯一最佳配比**。

Day 编号按有效完成推进，不应自动按日期越过未掌握单元。可以跳级，但必须进行陌生题材诊断。

## 4. 初始复习与动态支架

提供第 1、3、7、14 **学习日后**的主动检索建议（不是固定日历，也不是文献保证的最优间隔）；内容要改成新题，避免只是重读旧答案。

按真实表现建议：
- **0–1/4**：先复习概念与范例，在新情境中练一道较短题。
- **2/4**：保持当前主题，换题独立再试。
- **3/4**：进入下一学习日，安排间隔检索。
- **4/4**：增加无提示、跨领域研究问题，检验高阶迁移。

这是课程的启发性决策规则，不是自动诊断系统。评定依赖真实答案，不能从完成教材文件推断熟练程度。

## 5. 四维评价

- **Accuracy 0–4**：语法、词义、术语与命题语义。
- **Clarity 0–4**：信息结构、句间衔接、段落中心和阅读负担。
- **Scientific reasoning 0–4**：主张—证据相容、竞争解释、可检验性。
- **Transfer 0–4**：能否将方法用到未经示范的新情境，不只是复述模板。

注意具体题目可能只考其中一两个维度。不能用同一个混合总分掩盖“语言正确但科学推理错误”。

## 6. 质量检查

1. **教学真实性**：每一天课程是否能由一名真实学习者直接使用？
2. **科学准确性**：哪些是教学假设，哪些是来源支持的事实？是否混淆因果、预测和模型行为？
3. **英语准确性**：例句自然且语义明确，答案不偷换主张；句式不是机械拼接。
4. **答案质量**：评分依据具体，提供多种合理可能性的判断标准。
5. **动态评估**：设置延迟新题与错误复现检查；未经学习者实践不可登记学习效果。
6. **安全/版权**：不粘贴大量受保护论文内容，不在公共课件泄露私人文件、ID 和作文。

## 8. 所借鉴的公开证据（详见来源审计）

[Dunlosky et al., 2013](https://www.psychologicalscience.org/publications/journals/pspi/learning-techniques.html)：分散练习、检索练习的广泛支持。
[The Learning Scientists](https://www.learningscientists.org/blog/2016/8/18-1)：检索、间隔、交错、具体例子等策略。
[EEF 2025](https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/metacognition)：将计划、监控、评价和示范嵌入真实学科任务。
[Academic Phrasebank](https://www.phrasebank.manchester.ac.uk/about-academic-phrasebank/)：科学写作的修辞动作/交际功能。

这些来源不构成对**本项目特定分钟数、28天长度或长期个人效果**的直接试验验证。
