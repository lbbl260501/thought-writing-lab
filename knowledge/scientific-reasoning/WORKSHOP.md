# D 组迁移工作坊｜从论文理解到独立科学问题构建

> 下列所有任务情境都是本研究室创建的**假想研究条件**。它们不是论文已经得到的实验结果，也不是用户的实际研究数据。本文件供 F 转换为正式课程、Q 挑战科学推理、HQ 审定训练标准；私人作答和分数不在此记录。

## Workshop 1：PET/CT 的非对称信息与条件算力分配

### 情境

有一套 PET/CT 肿瘤分割系统，开发者认为 PET 更适合定位病灶、CT 更适合约束解剖边界，却发现（尚待实测）不同病例、病灶位置与观测质量可能改变这两者的边际作用。系统部署时还有严格端侧延迟预算。

### 独立任务

1. 将“PET 是主模态，CT 是辅助模态”分解为：结构先验、数据统计现象、待检验命题。不得把这三者混用。
2. 分别写出**融合精度问题**、**模态可靠性问题**和**预算路由问题**的输入、输出、约束与目标评价。每个问题给一个最可能推翻它的反例。
3. 给出 `x`（病例/病灶）、`b`（预算）、`m`（模态可用性）和 `L`（损失）等变量，提出可检验的条件资源分配命题；解释为何直接遮蔽 PET 再算 Dice 不等于无偏模态贡献估计。
4. 设计最少四组方法：PET→CT、CT→PET、对称融合、条件路由；控制参数与预算。分层报告小病灶、低摄取、明显生理摄取、错位与跨中心情境。
5. 用三句话写出一条 **phenomenon → hypothesis → evidence obligation** 逻辑链，不要直接引出某个模块名。

### 参考诊断，不是唯一答案

“某模态总更重要”通常过强。更谨慎的科研目标是给出明确的 **在固定任务、病例条件和计算预算下** 的性能—成本取舍，并区分对当前模型的干预价值和该模态的临床诊断价值。若某一模态在更多病例中获得优势，也不能无条件推广到未观察的肿瘤类型或扫描协议。

基础证据出发点：[CDFP-Net](case-05-asymmetry-vs-adaptation.md)、[MMA-LTS](case-04-identity-over-count.md)、[Locor](case-03-local-assumption.md)。

## Workshop 2：髁突骨折复位与固定的联合术前规划

### 情境

假定某虚拟手术规划系统能给出接近解剖目标的复位姿态，但所选姿态可能使可置钉空间不足。某些容易固定的姿态也可能降低关节形态复原度。患者特异骨性约束可由 CT 观察，但软组织、受力、材料属性和真实暴露范围存在不同程度的不确定性。

### 独立任务

1. 区分三个任务：`reduction-only`（只优化复位）、`fixation-only`（在给定复位下选固定）、`joint planning`（联合优化）。分别写出被优化对象与约束。
2. 构造反例：某姿态令复位误差更小，但不能在安全区内实现足够稳定的固定。解释单目标最优解为什么不等于联合可行解。
3. 提出患者特异规划状态 `s=(R,F,A,U)`：R=骨块姿态、F=固定方案、A=解剖与可达性条件、U=不确定性。说明哪些量来自术前影像、哪些来自模型假设或额外测量。
4. 构建**约束与Pareto目标**两种表述：先有硬安全约束，再优化复位与固定的目标；讨论结果是否唯一，及何时不应将临床风险当作易交换的软惩罚。
5. 设计“依次先复位后固定”与“联合候选规划”的公平对比；使用同一病例集和相同允许操作，检验可行率、解剖误差、固定机械性能、专家可执行性和规划开销。
6. 若 CT 无法直接给出真实材料参数，说明该参数的来源、校准、敏感性、可信区间；不允许把模拟力学最优写成已经获临床验证。

### 参考诊断，不是唯一答案

严谨的科学问题不只是“强化学习和图搜索哪一种更先进”，而是**复位与固定之间存在怎样的双向约束，使阶段式优化可能系统性错失可行方案？** 只有在实际比较与病例分层中得到有区别的预测，才能从联合工作流上升到一般建模结论。可用 [CAMOS](case-02-workflow-inversion.md) 的任务边界和 [Locor](case-03-local-assumption.md) 的假设局部化训练这一步。

## Workshop 3：森林伪变化检测的概念与评价重构

### 情境

多时相遥感影像中，采集季节、照明、传感器、配准与物候变化可能导致明显像素差异，然而土地覆盖类别或某些生态状态并未发生研究者关心的变化。

### 独立任务

1. 在论文开头分别定义 **observation change**（观测差异）、**semantic change**（语义类别变化）与 **ecologically meaningful change**（生态过程改变）；说明它们可能重叠但不能同义。
2. 给出两套竞争解释：H1 模型过度响应成像条件变化；H2 标注任务将有生态意义但无类别变化的事件当作伪变化。不同定义下，哪类样本会翻转“误报”判定？
3. 设计跨季节、跨传感器、配准扰动及真实火灾/采伐变化的实验，区分数据增强带来的性能提高与真正对稳定语义信息的依赖。
4. 确定错检/漏检的真实应用代价，并写出一种比单一 IoU 更能解释现实失败的评价组合；说明哪些是评价对象改变，哪些只是指标增加。

### 参考诊断，不是唯一答案

首先定义“变化”的科学对象，接着定义何为伪变化；若对象定义不同，指标分数不能直接横向比较。借鉴 [Shortcut](case-06-shortcut.md) 的信号干预、[IRM](case-07-irm.md) 的环境可辨识性和 [WILDS](case-08-wilds.md) 的评价域设计。

## 对抗式审稿清单（Q 可直接采用）

- **问题是否先于算法？** 去掉方法名后，问题仍可独立陈述吗？
- **竞争解释是否真实竞争？** H1/H2 是否在具体实验条件下预测不同？
- **干预解释是否因果过强？** 干预是否同时引入伪影、重新训练、额外容量或数据泄漏？
- **临床终点是否混淆？** 生成外观、规划可达性、执行成功与患者获益是否被偷换？
- **评价是否可部署？** 实测延迟/显存、中心偏移、病例分层、统计区间是否与主张匹配？
- **证据层级是否清楚？** 作者/评审者/分析者/未来实验是否分别标识？

## 通向科学写作的下一步

完成上述任一任务后，把分析压缩为一段英文引言（100–140 words），逐句标注科学主体、动词、客体、叙事动作、推理前提和证据需求，再交给 C 组检查英语语言实现。英文段落的华丽程度不替代假设与实验审查；本工作坊不提供固定句子模板或声称唯一标准答案。
