# 原材料细读研究｜从八个初步案例到十二篇正文比较

2026-10-14 · Issue #5 深化稿 · 待 HQ/Q 审核，未作为正式课程发布。

本轮新增 8 个文献样本，并深化初版 CAMOS、Locor、MMA-LTS、CDFP-Net。库内由 8 个扩至 **16 个不同论文样本**；本轮有 **12 篇正文选定部分的实际核读**。这不等于 16 篇全文审计，也不等于独立复现。新样本按问题类型而非年度排行榜选取，属于目的性比较样本，不是穷尽检索或系统综述。
